# Pesona Wisata Sumatera Utara 🌿

Website katalog mini interaktif yang menampilkan daftar destinasi wisata unggulan di Provinsi Sumatera Utara, mulai dari wisata alam, budaya, hingga wisata edukasi keluarga.

## Fitur Utama
- **Pencarian Real-time**: Mencari destinasi berdasarkan nama tempat atau kabupaten/kota.
- **Filter Kategori**: Menyaring destinasi berdasarkan kategori (*Semua*, *Wisata Alam*, *Budaya & Sejarah*, *Edukasi & Keluarga*).
- **Pop-up Detail Wisata**: Menampilkan informasi lengkap mengenai lokasi, estimasi harga tiket masuk, dan deskripsi destinasi.
- **Desain Responsif**: Tampilan menyesuaikan ukuran layar desktop maupun ponsel.

## Teknologi yang Digunakan
- **HTML5** (Struktur halaman)
- **CSS3** (Styling, Flexbox, CSS Grid, dan Modal animasi)
- **JavaScript (Vanilla)** (Manipulasi DOM, filter data, dan pencarian dinamis)

## Cara Menjalankan Proyek
1. Clone atau unduh repositori ini ke komputer Anda.
2. Buka folder proyek `wisata-sumut`.
3. Klik dua kali pada file `index.html` untuk membukanya langsung di browser (Chrome, Edge, atau Firefox).
