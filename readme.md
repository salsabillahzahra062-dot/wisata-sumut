# Katalog Wisata Sumatera Utara

Mini web app katalog destinasi wisata di Provinsi Sumatera Utara yang dibangun menggunakan HTML semantik, CSS responsif, dan Vanilla JavaScript.

## Fitur Utama
- **Struktur Semantik:** Menggunakan elemen HTML5 (`header`, `main`, `section`, `article`, `dialog`, `footer`).
- **Desain Responsif:** Tata letak grid yang menyesuaikan otomatis dari layar ponsel hingga desktop.
- **Pencarian Real-time:** Mencari destinasi berdasarkan nama tempat, kabupaten/kota, atau deskripsi.
- **Filter Kategori:** Menyaring destinasi berdasarkan kategori *Wisata Alam*, *Budaya & Sejarah*, dan *Kuliner & Kota*.
- **Modal Informasi Detail:** Menampilkan jam operasional dan estimasi harga tiket.

## Cara Menjalankan
1. Unduh atau clone repositori ini.
2. Buka file `index.html` langsung di browser (Chrome, Edge, Firefox, atau Safari).
